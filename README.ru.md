# DW Bot

**Музыка, видео и фотогалереи прямо в Telegram**

![Python 3.13](https://img.shields.io/badge/Python-3.13-3776AB?logo=python&logoColor=white)

Отправьте название песни или ссылку. При необходимости выберите трек
или качество видео и получите готовый файл в чате.
Работает на aiogram, поиске Spotify, yt-dlp и gallery-dl.

## Возможности

| Возможность | Описание |
| --- | --- |
| 🔎 **Поиск музыки** | Поиск треков через Spotify с выбором из нескольких результатов — до 10 |
| 🎧 **Аудио в MP3** | Извлечение звука, добавление метаданных и обложки при их наличии |
| 🎬 **Выбор качества YouTube** | Доступные разрешения видео и вариант «Только звук» |
| 🖼️ **Фотогалереи TikTok** | Отправка фотографий медиагруппами до 10 изображений |
| ⚡ **Inline-отправка** | Отправка поддерживаемых медиа в другие чаты через `@your_bot <URL>` |
| 🍪 **Cookies для YouTube** | Повтор неудачных запросов извлечения с авторизованной сессией |
| 🌐 **Раздельные прокси** | Независимые настройки для медиасервисов и Telegram |
| 🐳 **Docker Compose** | Python, FFmpeg, ffprobe и Deno уже включены в образ |

Spotify предоставляет результаты поиска и метаданные. Аудио для треков Spotify
бот ищет на YouTube по исполнителю и названию; из самого Spotify звук не скачивается.

## Быстрый старт

Нужны Docker Compose, токен Telegram-бота от BotFather, client ID и client secret
приложения Spotify. Текущая конфигурация требует данные Spotify даже в том случае,
если вы планируете скачивать только видео.

1. Скопируйте [`.env.example`](.env.example) в `.env`.
2. Заполните обязательные реквизиты:

   ```dotenv
   BOT_TOKEN=your-telegram-bot-token
   SPOTIFY_CLIENT_ID=your-spotify-client-id
   SPOTIFY_CLIENT_SECRET=your-spotify-client-secret
   ```

3. Запустите бота из корня проекта:

   ```bash
   docker compose up -d --build
   ```

Откройте бота, отправьте `/start`, затем `Daft Punk Get Lucky` или поддерживаемую ссылку.

Бот получает обновления через long polling: публичный вебхук не нужен.
Compose подключает `./data` к `/app/data` для необязательных файлов cookies.

## Использование

| Что отправить боту | Результат |
| --- | --- |
| Название песни или исполнитель и название | Результаты поиска Spotify с кнопками выбора трека |
| Ссылка на трек Spotify | MP3 с метаданными Spotify и обложкой при её наличии; короткие ссылки `spotify.link` раскрываются |
| Обычная ссылка на видео YouTube | Доступные разрешения и вариант «Только звук» |
| Ссылка YouTube Shorts | Скачивание видео |
| Ссылка YouTube Music | Скачивание аудио |
| Ссылка на видео или фотопост TikTok | Видео или фотогалерея; короткие ссылки раскрываются автоматически |
| Ссылка на видео Instagram или Pinterest | Скачивание видео при поддержке экстрактором и наличии доступа |
| Ссылка на VK / VK Видео | Скачивание клипа или видео; поддерживаются пути `/clip`, `/clips` и `/video` |
| `/help` | Инструкция в Telegram |

Поддерживаются источники, которые обрабатывает
[`SearchService`](app/services/search_service.py), хотя сам yt-dlp работает
с большим числом сайтов. Альбомы и плейлисты Spotify не поддерживаются.
Интерфейс бота в Telegram сейчас на русском языке.

### Inline-режим

В BotFather включите `/setinline` и установите `/setinlinefeedback` на **100%**.
Событие выбора результата нужно боту, чтобы заменить временное сообщение файлом.

В любом чате напишите:

```text
@your_bot https://www.youtube.com/shorts/VIDEO_ID
```

Выберите **«Скачать»**. Бот отправит **«Готовлю файл...»**, подготовит медиа
и заменит это сообщение готовым результатом.

- Inline-режим принимает ссылки, а не поисковые запросы по названию песни.
  Обычные ссылки YouTube требуют выбора качества — отправляйте их напрямую боту.
- Из фотогалереи TikTok в inline-режиме отправляется только первое изображение.
  Для получения всей галереи отправьте ссылку напрямую боту.
- Без `INLINE_CACHE_CHAT_ID` каждый пользователь должен сначала открыть личный
  чат с ботом. Туда временно загружается медиа для получения Telegram file ID.
- При заданном `INLINE_CACHE_CHAT_ID` временные загрузки идут в указанный чат
  или канал. Дайте боту право отправлять туда медиа.
  После использования бот пытается удалить служебное сообщение.

## Настройки

Переменные окружения и `.env` загружаются через
[`app/core/config.py`](app/core/config.py).

| Переменная | Обязательна | По умолчанию | Назначение |
| --- | :---: | --- | --- |
| `BOT_TOKEN` | да | — | Токен Telegram-бота |
| `SPOTIFY_CLIENT_ID` | да | — | Client ID приложения Spotify |
| `SPOTIFY_CLIENT_SECRET` | да | — | Client secret приложения Spotify |
| `COOKIES_FILE` | нет | — | Имя файла cookies в формате Netscape внутри `data/` |
| `MEDIA_PROXY` | нет | — | Прокси для Spotify, yt-dlp, gallery-dl и скачивания обложек |
| `TELEGRAM_PROXY` | нет | — | Прокси для подключения к Telegram Bot API |
| `LOG_LEVEL` | нет | `INFO` | `DEBUG`, `INFO`, `WARNING`, `ERROR` или `CRITICAL` |
| `SEARCH_LIMIT` | нет | `5` | Количество результатов Spotify; от 1 до 10 |
| `MAX_UPLOAD_SIZE_MB` | нет | `49` | Максимальный размер каждого медиафайла; не менее 1 МБ |
| `INLINE_CACHE_CHAT_ID` | нет | — | ID чата или канала для временных inline-загрузок |
| `IMAGE_TAG` | нет | `latest` | Тег Docker-образа, используемый Compose |

Неиспользуемые прокси оставьте пустыми. `MEDIA_PROXY` не применяется к первому
HTTP-запросу, раскрывающему короткую ссылку TikTok. `IMAGE_TAG` — настройка
Compose; остальные переменные настраивают приложение.

### Cookies для YouTube

1. Поместите файл cookies в формате Netscape в `data/youtube.cookies.txt`.
2. Укажите `COOKIES_FILE=youtube.cookies.txt` в `.env`.
3. Пересоздайте контейнер, чтобы применить изменение окружения:

   ```bash
   docker compose up -d
   ```

Сначала бот пробует извлечь данные без cookies, затем повторяет запрос с ними
при ошибке извлечения. Пустой `COOKIES_FILE` отключает повтор с cookies.
Если имя задано, а файл отсутствует, проверка настроек не позволит запустить бота.
Cookies не гарантируют доступ к материалам с ограничениями.

## Локальная разработка

Используйте Python 3.13. Установите FFmpeg и ffprobe для конвертации аудио,
объединения видео и проверки потоков, а также Deno для JavaScript-проверок YouTube
в yt-dlp. Программы должны быть доступны через `PATH`; в Docker-образе они уже есть.

<details>
<summary>Linux / macOS</summary>

```bash
python3.13 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
mkdir -p data
# Заполните .env перед запуском.
python main.py
```

</details>

<details>
<summary>Windows PowerShell</summary>

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
New-Item -ItemType Directory -Force data
# Заполните .env перед запуском.
.\.venv\Scripts\python.exe main.py
```

</details>

Запускайте команды из корня проекта, чтобы приложение нашло `.env`.

### Проверки и тесты

```bash
python -m app doctor          # настройки и внешние программы
python -m app doctor --json   # тот же отчёт в JSON
python -m pip install -e ".[dev]"
pytest                        # офлайн-набор тестов, без сети и токена бота
ruff check .
```

`doctor` проверяет настройки, FFmpeg, ffprobe, Deno, каталог `data/`, схемы
прокси, файл cookies и лимит размера файла, а затем завершается с кодом `1`,
если обязательная проверка не прошла. Запускайте его после правки `.env`
и перед публикацией бота; в образе он уже доступен.

`python -m app` и `python main.py` равнозначны; `python main.py doctor` тоже работает.

## Управление и диагностика

```bash
# Следить за логами бота
docker compose logs -f --tail=100 download-bot

# Пересобрать после изменения кода или зависимостей
docker compose up -d --build

# Остановить бота
docker compose down
```

Loguru пишет в stderr. На уровне `INFO` видны ход запроса и этапы скачивания;
`DEBUG` добавляет подробности извлечения и доступных форматов.
Логи зависимостей из стандартного logging передаются начиная с `WARNING`.

<details>
<summary>Скачивание завершается ошибкой или Telegram не принимает файл</summary>

Найдите проблемный провайдер в логах бота. При ошибках извлечения YouTube
проверьте доступность Deno, cookies и соединение. Для видео TikTok после ошибки
скачивания через yt-dlp бот пробует gallery-dl.

Для большого видео YouTube выберите меньшее разрешение. Увеличение
`MAX_UPLOAD_SIZE_MB` не меняет лимиты загрузки Telegram.
Приватные, удалённые и недоступные в регионе материалы могут не скачиваться.

</details>

<details>
<summary>Inline-сообщение остаётся на этапе «Готовлю файл...»</summary>

Проверьте, что inline feedback установлен на 100%, и посмотрите логи бота.
Откройте личный чат с ботом или задайте доступный `INLINE_CACHE_CHAT_ID`.
Ссылки, требующие выбора трека или качества, отправляйте в личный чат.

</details>

## Структура проекта

Обработчики Telegram принимают запросы и отправляют файлы. Сервисы разбирают
ввод и координируют провайдеры; провайдеры обращаются к внешним платформам
и обрабатывают медиа.

```text
app/
├── bot/          # Обработчики Telegram, роутер и клавиатуры выбора
├── core/         # Настройки, логирование и правила разбора ссылок
├── errors/       # Прикладные ошибки и сообщения пользователю
├── models/       # Виды запросов, метаданные треков и форматы видео
├── providers/    # Spotify, yt-dlp, gallery-dl, обложки и MP3-теги
└── services/     # Разбор ввода, поиск и координация скачивания

tests/            # Офлайн-набор тестов pytest
data/             # Необязательные cookies; подключается через Compose
main.py           # Точка входа (обёртка над `python -m app`)
docker-compose.yml
Dockerfile
```

Скачанные файлы создаются во временных каталогах и удаляются при завершении
обработки запроса. Постоянную медиатеку бот не хранит.

## Приватность и ограничения

- Поиск Spotify и подбор аудио на YouTube могут вернуть другую запись,
  ремикс или концертную версию. Проверяйте полученный трек.
- Изменения платформ могут потребовать обновления зависимостей. Произвольные
  ссылки, плейлисты Spotify и фотогалереи Instagram не поддерживаются.
- Файл должен укладываться и в настроенный размер, и в лимиты Telegram.
- Скачивайте и распространяйте только материалы, на использование которых у вас есть право.
